# Dashboard Project

Development of Business Intelligence Dashboard for Procurement and Inventory Monitoring using Power BI.

## SQL Views

- `vw_inventory_dashboard.sql`: view utama untuk dashboard inventory
- `vw_inventory_monitoring.sql`: view untuk monitoring stok
- `vw_inventory_movement.sql`: view untuk pergerakan barang masuk dan keluar

## Cara Pakai

1. Buka SQL Server Management Studio (SSMS).
2. Jalankan masing-masing file `.sql` pada database yang sesuai.
3. Hubungkan Power BI ke view yang sudah dibuat.
